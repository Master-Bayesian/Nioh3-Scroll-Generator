# Nioh 3 Studio 0.8.3

Download `Nioh3Studio-0.8.3-win-x64.exe` and run it directly, or use the signed
in-app updater. No manual extraction, Python, Node.js, Electron or Cheat Engine
setup is required.

- Generate equipment from seeds, search selected effects and review records
  before adding them to a save. Legal mode retains its item-grant route and
  player-progress limits; Modded mode remains available.
- On PC v2.02, preview game-generated equipment and confirm one live addition.
  Save at a shrine afterward to persist it.
- Preview scroll completion, replacement and extra-painting branches for up to
  five rounds. This read-only prediction covers PC v2.02 NG3, type `0xE604`,
  rarity 4; Revelation and automatic slot selection remain unverified.
- Explain denied game-process access with two conditional recovery paths:
  restart the tool as administrator when the game runs elevated, or disable
  the game's administrator setting and restart both before retrying a read.
- Improve non-Steam installation discovery. Settings can select the actual
  game EXE and show its file version and operation capabilities.
- Improve equipment drafts and selection following, save-plan recovery,
  bounded save/backup/restore reads, and access to long-plan confirmations.
  Equipment filtering, sorting, naturalness verdicts and effect labels are also
  improved.

The primary target is PC v2.02 (`2.0.2.0`). PC v2.01 retains its existing offline
and registered scroll/count paths; seeded native equipment addition is
unsupported. PC v2.00.02 retains its existing offline scope. Older experimental
capabilities remain labeled, and unknown versions are refused.

Return to the title screen before editing a save file, then load it in game.
Keep an independent full-account backup. Automatic backups and recovery checks
remain enabled.
