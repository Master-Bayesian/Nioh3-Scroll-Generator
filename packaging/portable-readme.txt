Nioh 3 Scroll Editor 0.7.0 - Windows x64

Extract the entire ZIP to a writable folder, then launch Nioh3ScrollEditorV2.exe.
Keep all files together. Python and Cheat Engine are not required.
Use the language button above Settings to choose Chinese, English or Japanese.

Search: filter effects/Grace for equipment bonuses, or enemies/rules/terrain for missions.
Keep up to 50 scrolls each in Favorites and the cart. Choose which cart entries to add.
Choose live addition while controlling your character, or save-file addition at the title screen.
Every addition creates a verified backup. Save normally in the game after live changes.
Use Backup management to inspect or restore backups; restoration requires the title screen.

Editing effects in a save is local; recipients regenerate effects from the seed.
Enemy, terrain, rule and maximum-attempt overrides are temporary. Stop them before closing.
Remaining attempts are a separate instance edit, with a backup and explicit review.
Live memory features currently require the verified PC v2.01 build.

Updates replace the complete portable directory, never individual files.
The old Tk updater cannot install this ZIP: v0.6 users must download and extract V2 once.
V2 update manifests use the existing official Ed25519 signing key.
Executables do not have a Windows Authenticode certificate. The local build manifest
checks file integrity; it is not a publisher signature.

For a problem report, use Settings > Copy log. Runtime logs rotate at 4 MiB per file,
with five files retained. Backups and operation receipts remain available for recovery.
See dependency-manifest.json, THIRD_PARTY_NOTICES.md and licenses/ for dependencies.
