## Completed changes

- Favorites and cart independently cap at 50. Hollow/filled stars toggle favorites in results and cart; favorites can enter the cart and copy seed ID, rarity, or both. Favorites are persisted in Electron userData/favorites.json through serialized, flushed atomic replacement. Private candidate transfers remain broker-owned and retain their exact GenerationContext and R4 records across restart. Invalid files are preserved for recovery.
- Duplicate effect selections now have occurrence IDs and independent thresholds. Final matching assigns distinct generated slots with backtracking for alternatives. Coarse accelerator filtering remains permissive; no RNG, R4 finalizer or core numerical semantics were rewritten.
- Live batches report completed/total and can stop before the next child. In-flight insertion is never interrupted or replayed. Verified items become unselected and marked added; recovery uses the original submitted keys rather than later selection state. Each child retains its automatic backup requirement.
- Synthetic native fault coverage includes debugger conflict, active hardware breakpoints, transient restoration failure, process exit, and retained ownership during repeated restoration failure. Fixed debugger setup rejection at the initial attach breakpoint and exited-thread handling. These are isolated fixture tests, not universal game-state tolerance claims.
- Signed local beta update fixtures exercise real extraction, complete manifest validation, replacement and failed-launch rollback. Locked directories now use same-volume atomic Directory.Move instead of potentially partial PowerShell Move-Item. Invalid archives and tampered staging are rejected. Production pinned key/origin policy is unchanged; no real feed was published.
- English and Japanese UI enabled with 529 source messages and 1,560 game-name translations. JSX presentation translation preserves option values and internal query semantics. Unknown game names remain explicit effect IDs instead of invented translations. Human language review is still needed.
- Temporary seed-scoped challenge capacity editing is connected (1–7, PC v2.01 only). Entry signature and seed argument EDX were verified from retained reverse-engineering evidence. An executable x64 fixture proves target/non-target behavior. Live acceptance remains pending. The UI accurately explains that an enabled override persists until stopped or the game exits; automatic reload disarming is not implemented.
- Production UI moved from apps/search-demo-v2 to apps/workshop; readable formatting and bounded component extraction include collections, scroll preview, presentation/localization and error formatting. Larger workspace decomposition is deferred to avoid unnecessary regression risk.
- Existing bounded logs (five 4 MiB segments), three-batch search history, legacy Tk and native CE-free insertion remain intact. R5 load conversion/icon discrepancy is explicitly excluded as requested.
