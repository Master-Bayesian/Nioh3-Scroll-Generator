# v0.7.4 product record

Status: **published stable release**

Created: 2026-09-12

## Goal

Deliver the scoped UI consistency work and exact native Crucible Wraith enemy
filter while preserving the existing generation and write contracts. Equipment
and Soul Core generation/editing are deferred to the v0.8.0 product line because
they introduce new generation, data, and write contracts.

## Shipped product work

### `ENEMY-STATE-TERMINOLOGY`: native localized naming

- The player-facing names are confirmed from the official Nioh 3 manual:
  Simplified Chinese `地狱附身`, English `Crucible Wraith`, and Japanese
  `地獄憑き`.
- Sources: [Simplified Chinese manual](https://www.gamecity.ne.jp/manual/nioh3/chs/6400.html),
  [English manual](https://www.gamecity.ne.jp/manual/nioh3/eng/6400.html), and
  [Japanese manual](https://www.gamecity.ne.jp/manual/nioh3/jpn/6400.html).
- `possessed` may remain an internal state identifier, but `Possessed` is not
  the official English player-facing label.
- Preview cards use compact text markers: zh-CN `附身`, en-US `Wraith`, and
  ja-JP `憑き`; the full official name remains in tooltip, accessibility, and
  help text as applicable.

### `APP-UPDATE`: launch and manual update checks

- After updater startup readiness, the packaged application performs one
  update check on every launch.
- When a newer update is found, the application asks the user whether to
  update, at most once for that launch; it defers the prompt while another
  dialog is open.
- Settings retains a working manual `Check for updates` action for an
  explicit recheck.

### `SCROLL-PREVIEW`: metadata typography

- Keep the recommended level and challenge-capacity labels aligned with their values on the same row.
- Use a consistent type role and line height for each label/value pair.
- Verify the result in all three locales and at representative window sizes and display scaling.

### Application typography audit

- Inspect the current UI for accidental size, weight, and line-height divergence.
- Prefer consolidating repeated values into a small type scale when the audit finds real inconsistency.
- Do not restyle the application merely to satisfy this work item; preserve intentional hierarchy.

## Research integration boundary

- Native captures and the reviewed Pro handoffs established the supported
  Crucible Wraith assignment and replay path used by the exact filter.
- The product exposes that state only for eligible low-pool enemy variants.
  Entry-dependent Curse state and the ordinary Expedition enemy-count difference
  are not offered as search filters.
- The research evidence supports this shipped enemy-state feature; it does not
  establish any broader equipment, Soul Core, or save-write capability.

The future legal equipment generator and noncanonical affix editor remain separate v0.8.0 concepts with separate evidence and safety boundaries.

## Acceptance status

- Native WebView2 acceptance passed in Simplified Chinese, English, and
  Japanese, including compact localized Crucible Wraith labels, paired preview
  typography, compact enemy conditions, and favorites geometry.
- The startup controller and isolated update UI passed the once-per-launch
  prompt and Settings manual-recheck scenarios without a live update download.
- Clean hosted build, signed feed, packaged startup, update replacement and
  rollback, one-file identity, and public redownload acceptance all passed.
