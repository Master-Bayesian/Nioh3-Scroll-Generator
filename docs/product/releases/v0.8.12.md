## Confirmed changes from 0.8.11

- Issue #50: the released seed-search contract and builder rejected hell weapons,
  and the legal-add UI did not expose hell conditions or preserve that context.
  Reuse the existing native hell conversion implementation and connect its
  supported seed search to the existing reviewed save-file addition workflow.
- Select the hell martial skill independently, preserve the selected result and
  progress/context binding through preview and queueing, and refuse stale or
  changed inputs. The effect seed does not determine the whole weapon.
- Correct the obsolete u16 guard in save equipment allocation to the already
  established native u32 contract. The owner's key 255761 reproduced the old
  failure on a copy. Zero, overflow and source/slot/counter drift still reject.
- Include the branch's previously validated PC v2.02 solo selector-one Crucible
  Wraith prediction. Existing native evidence is reused; unvalidated modes and
  selectors remain outside the certified scope.
- Stabilize the asynchronous E2E snapshot collectors: wait for a complete frame
  before parsing its body. The real completion-host transcript passes 197
  partial-header/body controls over 28 exchanges; original business assertions
  and timeouts remain in force. The related polling collectors use the same
  complete-frame rule. This changes test collection only.
