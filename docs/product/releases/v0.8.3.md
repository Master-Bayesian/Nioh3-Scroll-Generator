Status: **source checks passed; local candidate packaging pending; unpublished**

## Intended candidate

The proposed v0.8.3 slice adds save-file equipment generation from the game's own seed-based generator and extends equipment management. A natural item is a whole record produced from an item, rarity, seed, player difficulty/progress, and generation context; per-slot legality alone is not the intended guarantee.

The current source is branch claude/v082-integration, commit
2d133f7cd388bda390d542ea327b7f47398e049e. This is a candidate identity only.
The checkout was dirty at intake and the earlier test7 package is rejected as
release evidence.

## Scope and acceptance

Affected features: LEGAL-EQUIPMENT-GENERATION and EQUIPMENT-EDIT, reconciled in
FEATURES.md. This candidate targets offline seed search and record replay,
not native live inventory insertion.

Acceptance requires generator-exact records in the bounded save E2E, an
accepted packaged UI/search flow, and a clean frozen source. Real-save and
live-write acceptance are deliberately not part of this intake.

## Evidence and limits

- The research record reports emulator-to-port comparisons of 3,600 compact
  entries and 5,000 full records, plus 1,500 comparisons across difficulty and
  progress thresholds. Raw receipts for the latter two counts were not retained
  in the handoff.
- The Rust parity fixture contains 900 records and compares whole records byte
  for byte. A retained run passed; this is offline parity evidence.
- The research record reports that 1,013 of 1,318 owner-save items reproduce
  from their seeds. This is offline replay evidence, not acceptance of a save
  write or save/reload in game.
- The retained backend checks also include the character-edit E2E, seeded
  equipment-search path and replay audit listed in the readiness record.
- A host integration case reproduced an audit false positive when only a
  stored effect group key changed. Replay now compares that key; the same
  integration case and more than 1,000 generated replay cases pass after repair.
- Seed-search results now expire when their inputs change, and late responses
  are discarded. The mocked-bridge browser workflow passed 42/42 checks;
  TypeScript and the 1,115-message locale audit also passed.
- No live write or real-save test is scheduled for this intake. The owner set the
  maximum context boundary for a save-file workflow at returning to the title
  screen; shutting down the game is not required.
