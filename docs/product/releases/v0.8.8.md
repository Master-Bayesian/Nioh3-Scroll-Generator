# v0.8.8 engineering record

Status: **published 2026-10-09** (tag `v0.8.8`, commit `4234ec3`; [publication record](../../knowledge/TAURI_V088_PUBLICATION_20261009.md)), authorized by the owner ("加gpl3.0，然后同时推送发布刚刚的版本"). Base: `v0.8.7` (`49ce3e9`).

## Player-facing changes

- **Hell axes and dual swords.** The bundled hell martial-skill table started
  four rows late: the game's table at `[[Nioh3.exe+0x45B9E30]+0x5A8]` (header
  `0x20042200`, count at `+0x54`, 0x20-byte rows from `+0x58`: skill `+0x18`,
  weapon type `+0x1A`, minimum level `+0x1C`) has 43 rows, the bundle had 39.
  The axe (type 7191) had none, so every hell axe was unnatural; the ninja dual
  swords (21589) lacked `0xA475`. Added `0xA148` 碎地 / Earth Carver, `0xDD8A`
  大旋风 / Tornado Edge, `0xD3A9` 噬魂 / Soul Devourer and `0xA475` 影斩 /
  Shadow Slice (names read live from the zh-CN pool; en/ja from the locale
  captures). A test requires all 16 samurai and ninja weapon types to have hell
  skills. A sweep of all 3362 items found no other gap in effect, set,
  soul-core or skill names.
- **Scroll effect star.** Replacing a scroll effect kept the slot's `+0x0E`
  byte. In two owner saves, all 67 scroll effect ids carry star bit `0x04`
  exactly when their effect row has `+0x20` flag `0x08` (every 之深奥 and four
  others); the editor now sets or clears it with the effect.
- **License.** GPL-3.0-only (`LICENSE`, README, package manifests).

## Evidence

- Live, PC v2.02 title screen (2026-10-09): the 43-row table and the four
  names, read-only through CE.
- The scroll editor in a packaged build: 灵力增加量 → 武之深奥 set the star
  (`0x4A4C` → `0x44D4C`), and back cleared it. The star was not viewed in a
  game menu after a write.
