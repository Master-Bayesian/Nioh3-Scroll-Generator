## Goal

Emergency fix for two shipped problems: an NG3 scroll search that stopped at an
internal trial budget and read as an empty result, and a window/taskbar icon
that Windows stretched from a 16x16 bitmap. Generation, RNG, save, live-add, and
write contracts are unchanged.

## Shipped product work

### `SEARCH-CONTINUATION`: searches finish instead of stopping short

- Before: the desktop search submitted `page_trials = 1,000,000` with a total
  `job_trials = 10,000,000`. A reported three-rule special-rule combination
  (`一难横行（配件）80%`, `神器掉落率上升 10%`,
  `优先掉落率上升（素盏呜尊的恩宠）30%`) has its first match at pivot trial
  158,614,759, so the job ended with `stop_reason = budget_reached` and the
  status line read `本批找到 0 张绘卷`, indistinguishable from a genuinely
  empty result. v0.6.10 reached the same seed because the Tk search loop kept
  taking pages.
- After: `search.start` accepts an optional `continue_until_complete` flag.
  Absent or false keeps the previous bounded API; true keeps one job taking
  bounded pages until the requested result count, `family_exhausted`,
  cancellation, or a fail-closed error, and `page_trials` may be up to
  100,000,000 so the per-page overhead no longer dominates long searches.
- Preserved: candidate ownership across pages, checkpoint validation against the
  actual page budget rather than the old job stop, `NO_PROGRESS` /
  `RESULT_OVERFLOW` / `INVALID_CHECKPOINT` still fail closed without publishing a
  checkpoint, and resume tokens remain bound to query, context, execution
  policy, and continuation policy.
- Evidence: real native regression returns Seed `226061463` inside one job
  (candidate trial `158,614,759`, two pages of 100,000,000, 1.80 s); a
  100,000,000-trial page cancels in 31 ms and resumes from the saved checkpoint.

### `APP-ICON`: high-resolution window and taskbar icon

- The packaged ICO stored its 16x16 frame first. Tauri's codegen embeds
  `default_window_icon` from the first entry, so the window and taskbar icon was
  a stretched 16x16 bitmap. The asset now leads with 256x256 and keeps all seven
  original frames byte-identical; nothing was redrawn or upscaled in the file.
- Evidence: Tauri codegen output changed from a 1,024-byte (16x16) bitmap to the
  262,144-byte (256x256) frame, byte-identical to the ICO's 256 frame, and the
  native HICON render at 32 px is crisp instead of smeared.
