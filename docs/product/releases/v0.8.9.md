# v0.8.9 engineering record

Status: **published 2026-10-13** (tag `v0.8.9`, commit `6cdb466`, release run 38481648160), authorized by the owner ("这个版本差不多可以发布推送了"). Base: `v0.8.8` (`4234ec3`).

## Player-facing changes

- **Arc interface.** `apps/workshop/arc.css` layers the redesign over the
  legacy `style.css`. Fixed pixel heights and grid rows on text boxes became
  minimums (`tools/relax_fixed_text_boxes.mjs`, 141 declarations); every zh-CN
  element box measured the same before and after.
- **Item marks.** Protect is bit `0x04` and Favorite bit `0x20000` of the item
  record word at `+0x18`, identical for scrolls and equipment, in memory and in
  the save. Save plans and live edits carry `marks`; adding Favorite also sets
  Protect, as the game does.
- **Save summary.** The decrypted save header holds save time `+0x20`, level
  `+0x28`, play time in microseconds `+0x30`; the block is recognized by the
  words at `0x00`, `0x14` and `0x18`. The word at `0x10` differs per account
  and is not a format tag.
- **Live-checkpoint restore.** A backup holding only the main save restores
  that file alone; account, slot, size, SHA-256, decryption, pre-restore backup
  and rollback checks remain.
- **Launcher.** The one-file cache rename retries `PermissionDenied` for up to
  20 seconds; the failure dialog names antivirus first, opens the log folder,
  or downloads the same version's portable ZIP.
