# Nioh 3 Studio 0.8.14

Stable release candidate for LIVE-EQUIPMENT-ADD. This version adds optional effect-based seed search to the existing live equipment form. The native worker, manual seed path, backup checks, durable operation receipts, and save-mode Crucible search remain in scope.

The search uses the selected save's difficulty and progress. After saving at a shrine, use Reload on the live equipment page to refresh the target save before searching again. An explicit result selection expires when its source or inputs change. Confirmation requires a current prepared preview containing every wanted effect group. A valid operation UUID remains recoverable when cached effect requirements cannot be read.

The reviewed integration passed 117 browser assertions across three languages and 156 existing save-mode Crucible assertions. The UI and durable-operation models passed with expected counterexamples in their fault configurations. Release acceptance uses the exact signed Windows package and isolated scripted save and operation fixtures. Actual game insertion and subsequent in-game save persistence retain the prior evidence boundary.
