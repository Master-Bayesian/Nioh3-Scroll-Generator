# v0.8.4 engineering record

Status: **in development on `claude/v084-ui`; not packaged or published**

Base: `v0.8.3` publication record commit `a0623f1`.

## User-visible changes

- Settings opens a small menu beside the sidebar button (display toggles,
  game version, feedback, updates). Game version details open as a second
  panel from the menu instead of filling the menu with diagnostics.
- Equipment & items: owned and add lists filter by class, then weapon type,
  armor slot or accessory kind, with a samurai/ninja choice for armor. Counts
  show on each chip. The save-file and live add catalogs share this grouping
  and sort by type, then name (issue #30, part 1; set browsing is deferred).
- Equipment, item and add lists scroll; the eight-row pager is gone.
- The selected row shows an "unapplied" badge while the editor has unapplied
  changes; the edit state and the paused-follow note are badges (#17, #18).
- The save picker is one line on every page; the equipment page shows one
  reload button.
- Favorites is a sidebar page (#20).
- Backups show readable local times, newest first, with backup actions ahead
  of folder actions. The save worker now reports the backup directory's
  modification time (Unix milliseconds) in `timestamp`.

## Preserved

Save, backup, confirmation, recovery, live-add ownership and generation
behavior are unchanged. No contract schema changed.

- `npm run typecheck`, `npm test` (94 pass, 1 packaged-only skip), locale
  audit (1360 messages), `cargo clippy`/`fmt` for `nioh3-protected`.
- Visual check: the new bundle was run inside a live v0.8.3 WebView2 window
  over its native bridge (read-only; no game or save write), 1455x909 at DPR
  1.1, Chinese locale. English/Japanese and packaged acceptance are pending.
