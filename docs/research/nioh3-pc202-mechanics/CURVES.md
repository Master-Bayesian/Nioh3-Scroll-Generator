[返回伤害手册](./README.md) · [证据和复核入口](./PROTOCOLS.md#sources)

## 角色的七项属性

原生顺序是 **体／心／刚／武／技／智／咒**。技能名里的「技」、面板上的术力、装备上的「伤害反映」分别是不同输入。以「技」为例，加点先改变表中的忍术力和琢技相关数值；身上有对应反映词条且本次命中准入时，再拿**最终**忍术力查伤害反映表。[来源 1、8](./PROTOCOLS.md#sources)

| 属性 | 本版已核实的派生路径 |
| --- | --- |
| 体 | 体的表值与角色等级、刚的生命项共同进入生命基数；装备和其他来源还会修正结果。 |
| 心 | 精力基数取心对应行；有明确的精力基数契约时，才可重算换点后的上限。精力恢复还读取心与智各自的恢复列。 |
| 刚 | 负重上限按流派取不同列；另有生命贡献。装备重量取实际穿戴后的合计，再与本套上限比较。 |
| 武 | 读取属性表的武对应列，缩放后写入角色派生字段 `STAT+1A8`；能否参与武器攻击还要看武器的属性掩码。 |
| 技 | 琢技相关输入 `STAT+1BC` 与忍术力 `STAT+1C0` 分列重建。此表两列的基础样点相同；装备等后续来源可以改变最终读数。 |
| 智 | 参与精力恢复，另有独立表列写入 `STAT+1AC`。 |
| 咒 | 阴阳术力基数写入 `STAT+1C4`。已验证的消费者包括阴阳术力反映、自施修罗符、召水附武的术力加值。 |

**武器面板的属性补正。** 武器先选本武器、改造和槽位允许的属性，把各点数经表 `base90+1A` 换算，取允许值中最大的三项，按该武器的三项系数加权并除以 100 取整。得到的加值还经过武器基础值相关的递减：基础值的一半以内全额计入，超过之后余量逐步乘 0.8、按基础值的 0.1 分段计入，依原生顺序截断。最后与武器基础项合并。这是面板攻击的来源之一；后段「对伤害的反映（心／刚等）」是另一项词条。不同武器和改造没有一条通用的「某属性每点加多少最终伤害」曲线。[来源 1、3、8](./PROTOCOLS.md#sources)

### 负重、敏捷和坚韧

常规路径先比较重量 `W` 和最终容量 `C`。在 `0 < C`、`W ≤ C` 时取整数 **r = ⌊1000W/C⌋**。以下是无敏捷改善、无角色最低分覆盖时的初判。百分比显示可能舍入，边界应看整数。例如 `W=301, C=1003` 时 r=300，仍落在 A 范围。[来源 8](./PROTOCOLS.md#sources)

| 条件（从上到下） | 原生分 | 敏捷 |
| --- | ---: | --- |
| W > C | 0 | D，超重 |
| 已解锁 AA 且 r ≤ 200 | 100 | AA |
| r ≤ 300 | 80 | A |
| 301 ≤ r ≤ 700 | 50 | B |
| 701 ≤ r ≤ 1000 | 20 | C |

正的敏捷改善值可在容量内提高档位，未解锁时最高 A。角色最低分覆盖可将过低的分数抬到 20。最终显示从 `STAT+79C` 分类：解锁且 ≥85 为 AA，否则 ≥75 为 A，≥25 为 B，≥1 为 C，0 为 D。影响「敏捷反映」的是**最终原生分**。[来源 8](./PROTOCOLS.md#sources)

**坚韧**读最终的 `STAT+218`：0–129 为 C，130–259 为 B，**260 起为 A**，**320 起且已解锁为 AA**。例如 320 但未解锁，仍显示 A。当前优化器读取 `D+6D1` 作为 AA 解锁条件；敏捷的负重比例不参与坚韧分档。[来源 8](./PROTOCOLS.md#sources)

### 琢技、术力与精力耗尽

**琢技威力曲线。** 在已验证的武士武技路线上，输入 x 为最终 `STAT+1BC`，相邻点线性插值，两端取端点。设 n 为合格且不同的武技键数，命中包的主增量约为 `曲线(x) − 1 + 0.10 + min(0.10 × n, 0.50)`；非武技的对应路线上键数项按零。原机按单精度先乘再取小，临界点可能相差一个浮点末位。正的包输入还可与角色琢技加值、正的 `D+11C` 同入该命中的后段池。[来源 3、6](./PROTOCOLS.md#sources)

| x | 10 | 200 | 400 | 600 | 800 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 曲线(x) | 1.00 | 1.10 | 1.20 | 1.25 | 1.30 |

**阴阳术力的两个例子。** 普通自身 PvE 修罗符采用候选装备的阴阳术力；术力 0、413、635 的施加倍率约为 1.4000、1.4826、1.5270。已验证的召水附武分两次截断，`强度 = trunc(30 × 准备道具的千分比系数 / 1000) + trunc(术力 × 0.01)`，运算使用单精度。测试道具在术力 0／635／700 时分别为 37／43／44。一个施术动作的曲线不能替代其他忍术或阴阳术的专属动作值。**「待实证 / 暂未完全建模」**：任意术的伤害、消耗、持续时间随七属性变化的全集。[来源 7](./PROTOCOLS.md#sources)

**持续技要算到哪一下？** 满精力起手，按实际动作顺序扣费；在已验证的正消耗分支，剩余精力只要大于零，就可能打出最后一个动作，即使这次扣费大于余额。水形剑以动作和命中窗分别计数；不能拿精力上限除以「平均每击精耗」代替逐步回放。[来源 6、9](./PROTOCOLS.md#sources)

| 武技与起始条件 | 基础消耗与停止条件 | 它会怎样改变配装比较 |
| --- | --- | --- |
| 武士双刀·上段水形剑，耗尽路线 | 起手 200，交替段 70／80，收尾 200；升级分支、剩余精力、命中窗和目标类型均已绑定到该场景。 | 1237 精力的离线对照中，关闭两种减耗得 36 段接触；仅近战减耗 40，仅武技减耗 38，两者开启 44。它们是同一夹具的四次对照。 |
| 水形剑，满槽新发动琢技 | 初期豁免精力扣费，持续按住的这一路线会刷新计时。进入实际扣费阶段后，已验证的琢技因子为原消耗的 70%，再考虑本套装备。 | 新发动又不中断时没有「打到精力耗尽」的有限总伤；可比有限开场，最多三个动作、六次正面命中。读入已有琢技对象时还须看它所处的阶段。 |
| 忍者锁镰·薮斩（Reaper），普通耗尽路线 | 起手动作 25192 基础 230，后续 25193／25194 交替，各 115。逐步读取精力、敏捷和当前减耗字段。 | `D+2AC` 准入时，按已消耗精力的整数百分比查减耗：≤50% 为 5%，60% 为 15%，70% 为 30%，≥80% 为 40%，段间线性过渡。此证据限普通薮斩分支。 |

## 六种「伤害反映」查表

从**最终输入和词条档位**查下表，所得是送入装备池的百分数。例：装备重量原生值 350，档位 D-（g0），位于 300 的 2.3 和 400 的 2.7 之间，得到约 2.5，即给符合条件的池添加 **0.025**。同池已有其他增量时，跳字的相对增幅会更小。各表的横轴都是实际原生读数。[来源 3、8、10](./PROTOCOLS.md#sources)

| 词条 | 曲线键 | 横轴 |
| --- | --- | --- |
| 装备重量 | `8E2D` | 穿戴总重量 `STAT+7B8`；查表使用重量，敏捷分档另看重量／容量 |
| 忍术威力 | `4F75` | 最终忍术力 `STAT+1C0` |
| 阴阳术术力 | `5731` | 最终阴阳术力 `STAT+1C4`；本版全部断点、18 档均与忍术力表相同 |
| 敏捷 | `4354` | 最终敏捷分 `STAT+79C` |
| 打倒敌人数 | `F361` | 角色已绑定的击倒计数；计数未知且词条启用时，回放拒绝给分 |
| 爱用度 | `DD41` | 普通手持武器路径用 `floor(爱用度原始字段 / 100)`；须满足该武器、来源与包标记条件 |

表的每个单元从左至右是相邻六个原生档位，g0 是第 0 列，g17 是第 17 列。输出按百分数保留一位小数，**已列出所有原生断点和档位**。同一档在相邻断点间线性插值，表外取端点。[数据及读表方法](./PROTOCOLS.md#tables)
