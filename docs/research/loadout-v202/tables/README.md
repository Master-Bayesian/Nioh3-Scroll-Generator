# Readable native projections

Generated from the included runtime JSON by scripts/export-readable-tables.mjs. CSV is UTF-8 BOM for Excel. IDs remain authoritative; blank display values are native hidden/non-numeric output, not zero. Guardian rows show owner-approved levels 1..50 only; source JSON retains all captured native growth indices. Raw weights use native tenths; packed armor requirements have separate low/high-rarity bytes. These are native parameter records, including internal rows, not a proof of item obtainability. Set value_mode/base/growth require the bundled set calculation contract; they are not flat final values. Attribute indices are zero-based in game order.
